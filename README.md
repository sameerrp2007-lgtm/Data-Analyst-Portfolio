# Data Analyst Portfolio — Retail Sales Projects

A beginner portfolio demonstrating data analysis across Python, SQL, Excel, and Power BI using one consistent synthetic retail sales dataset.

## Projects
1. **Python:** data validation, KPIs, grouping, CSV summaries, and charts with pandas/matplotlib.
2. **SQL:** business questions using aggregation, grouping, date functions, subqueries, and sorting in MySQL 8+.
3. **Excel:** dashboard workbook with KPI summary, monthly trend chart, category chart, and summary sheets.
4. **Power BI:** CSV data, DAX measures, and a build guide for a one-page interactive dashboard.

## Dataset
300 fictional order rows spanning 2025. All records are synthetic and do not represent a real company or customers.

## How to use
- Start with `01_Retail_Sales_Analysis/README.md`.
- Open the Excel workbook in `03_Excel_Sales_Dashboard/`.
- Run SQL queries in MySQL Workbench using the included CSV.
- Follow the Power BI build guide to create and save your own `.pbix` report.

## Skills demonstrated
Data cleaning checks, KPI design, aggregation, trend analysis, category/city analysis, visualization, SQL querying, spreadsheet reporting, and BI dashboard planning.
